# 任务树验收用例

> 实现：test/orchestration/taskTree.test.ts；沿用 OpenLogos reporter；使用独立测试数据库。

| 用例 | 验收条件 |
|---|---|
| ST-S03-29 | 根任务已交付、审查子任务运行中时，进行中列表保留根和后代，频道计数按根任务 |
| ST-S03-30 | 深层子任务返回完整所属树及兄弟节点，父关系不依赖编号格式 |
| ST-S03-31 | 后代状态匹配时保留完整树，分页按根任务，后代不截断 |
| ST-S03-32 | 后代最近活动决定整组排序，同时间的子任务按编号自然排序 |
| ST-S03-33 | 跨层开放问题、审批和失败同归一个根任务，实际频道、待办计数一致 |
| ST-S03-34 | 处理完待办且审查完成后，整组恢复已交付，根执行状态保持原值 |
| ST-S03-35 | 累计分页窗口在排序改变后仍有唯一且完整的根任务 |
| ST-S03-36 | 搜索命中深层子任务时保留祖先，其他频道不混入结果 |
| ST-S03-37 | 已完成节点有待审批或可重试失败审批时，整组仍需处理 |

页面验证：任务树展开/折叠；点击子任务、通过父级导航返回；搜索后代时保留祖先；收件箱事项独立选中和分组折叠；窄屏入口保留任务树。
